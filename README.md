# Petit Musée · site internet

Site de présentation de l'application Petit Musée, publié sur https://petit-musee.fr avec GitHub Pages.

- `index.html` : page d'accueil
- `confidentialite.html` : politique de confidentialité et mentions légales (lien demandé par Google Play)
- `style.css`, `fonts/`, `images/` : mise en forme, polices et images
- `CNAME` : nom de domaine du site
